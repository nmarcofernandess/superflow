# Capture

1. Use `superflow new` com título e resumo humano do tema para criar PRD e status.
2. Use a skill PRD para registrar problema, promessa, escopo e aceite conhecidos.
3. Use Status para registrar o retrato disponível e a orientação em `Próximo trabalho`.
4. Encerre a captura. Quando houver execução autorizada, escolha Build e Plan conforme a necessidade de arquitetura e sequência.
