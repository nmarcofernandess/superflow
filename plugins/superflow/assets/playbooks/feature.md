# Feature

1. Leia PRD e status; confirme o recorte autorizado e as condições em `Próximo trabalho`.
2. Acione Analyst para dúvidas materiais e devolva conclusões ao contrato afetado.
3. Use Build se houver decisões de arquitetura a persistir; use Plan se houver sequência a coordenar. As escolhas são independentes.
4. Rode `superflow check spec <spec>` para conferir os artefatos existentes.
5. Execute o trabalho autorizado. Com plano ativo, escolha tasks pendentes com predecessoras concluídas e confira seu aceite; sem plano, siga o aceite do PRD e a orientação do status.
6. Use Review e as provas do projeto; para concluir, siga `fechar.md`.
7. Atualize o status quando mudar direção, autorização, espera relevante, relação, divisão de escopo ou handoff.
