# Retomar

1. Leia `status.md` primeiro.
2. Se houver `waiting_for`, confira se a condição acabou; remova-a somente com fonte real.
3. Se houver `depends_on`, confira os status dos IDs declarados.
4. Para execução aceita, leia PRD, SPEC e plan.json e escolha uma task pending cujas predecessoras estejam done.
5. Continue a capacidade necessária e atualize o retrato quando a situação mudar.

Não infira atividade online nem procure fases antigas.
